## 新导入项目

```bash
# 在项目根目录下创建虚拟环境
python -m venv venv
# 如果项目中有 requirements.txt 文件，可以直接安装：
pip install -r requirements.txt
# 生成数据库迁移文件
python manage.py makemigrations
# 生成数据库迁移文件
python manage.py migrate
# 启动开发服务器
python manage.py runserver
```
