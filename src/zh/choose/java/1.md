`Cool Admin(Java版)`一个很酷的后台管理系统开发框架,开源免费、Ai编码、流程编排、扩展插件、模块化
<!-- more -->

[官网文档-Vue3-后台管理系统](https://java.cool-admin.com/)

项目是前后端分离的，需要分别拉取前后端代码到本地，[源码仓库](https://java.cool-admin.com/src/introduce/src.html)

后端修改数据库配置，配置文件位于src/resources/application-local.yml
以 Mysql 为例，其他数据库适配中...

Mysql(>=5.7版本)，建议 8.0，首次启动会自动初始化并导入数据
```bash
# mysql，驱动已经内置，无需安装
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/cool?useUnicode=true&characterEncoding=UTF-8&serverTimezone=GMT%2b8
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver
```


3、启动后端服务
启动文件：src/main/java/com/cool/CoolApplication.java，控制台打印出下面信息，说明后端服务启动成功


访问：http://127.0.0.1:8001，你将会看到后端的欢迎页面
