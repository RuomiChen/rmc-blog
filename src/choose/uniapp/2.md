`Cool Uni`开源免费、uni-app脚手架、ui组件库、扩展插件、模块化,能够自动化生成 Service 请求和 Entity 类型描述，极大地减轻了 TypeScript（Ts）开发的负担，使开发过程更加智能化和高效。
<!-- more -->


[官网文档](https://uni-docs.cool-js.com/)

```bash
# 拉取代码
git clone https://github.com/cool-team-official/cool-uni.git
# 或
git clone https://gitee.com/cool-team-official/cool-uni.git
```

## 安装依赖
```bash
pnpm i
```
