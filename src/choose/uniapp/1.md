`unibest`是一个uniapp的框架，作者扬言是最好用的，于是站长把他收录到了选择中，各位游客可自行判断进行选择。不过这个框架可以整合UnoCss我觉得还是很不错的好吧。
<!-- more -->

[官网文档](https://unibest.tech/)

```bash
# 如果没有 pnpm，请先安装: npm i -g pnpm
pnpm create unibest
# 时不时加一下 @latest 标识，这样可以使用最新版本的 create-unibest
pnpm create unibest@latest
```


## 安装运行
```bash
pnpm i
pnpm dev     # 运行h5
pnpm dev:mp  # 运行微信小程序
pnpm dev:app # 运行App
```
